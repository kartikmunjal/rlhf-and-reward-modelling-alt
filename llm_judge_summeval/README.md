# LLM-as-Judge for Summarization Quality

This module extends the repository's reward-modeling work from short response
preferences to full-summary evaluation. It uses SummEval human annotations as
ground truth, a pointwise rubric judge, and a pairwise judge interpreted through
the same Bradley–Terry preference framework used elsewhere in the repository.

The complete pipeline is implemented; live judge execution is pending provider
credentials. The immutable design is in [`preregistration.md`](preregistration.md),
the machine-readable lock is [`study_config.json`](study_config.json), and the
prompt source is [`prompts.json`](prompts.json). [`data_manifest.json`](data_manifest.json)
records source and output hashes plus the exact article-disjoint split. Raw,
processed, and response-ledger data remain gitignored.

The implementation includes strict provider-native JSON schemas, pinned model
snapshots, append-only content-addressed ledgers, schema-identical retries,
transport backoff, resumability, a hard held-out-label seal, bidirectional
pairwise execution, Bradley–Terry fitting, ROUGE-L, Spearman and partial
Spearman estimands, Wilson intervals, source-article and pair-cluster bootstrap
intervals, cross-provider agreement, actual-token cost accounting, and a
fail-closed report generator.

## Run

Set `ANTHROPIC_API_KEY` and `OPENAI_API_KEY`, then run:

```bash
python3 scripts/run_summeval_study.py
```

That command deliberately stops after writing the development-only report.
Review `results/summeval_judge_v1/dev_report.md`; if the preregistered prompt is
accepted unchanged, resume the entire held-out matrix and final analysis with:

```bash
python3 scripts/run_summeval_study.py --approve-prompt-freeze
```

Every API step is resumable. Held-out calls cannot start unless the prompt
manifest proves that prompt bytes were frozen after a valid development run.
Final publication is refused below the preregistered 90% response-coverage
threshold. The conservative pre-run estimate is generated by
`scripts/estimate_summeval_judge_cost.py` into [`cost_estimate.json`](cost_estimate.json).

## Interpretation

The primary claim is intentionally narrow: Claude succeeds only if both
relevance and consistency reach the locked correlation threshold and each
paired bootstrap interval beats ROUGE-L above zero. Cross-provider agreement,
coherence, fluency, pairwise results, and bias mitigations are secondary and
cannot rescue a failed primary result. Length controls diagnose whether verbosity
mechanically explains apparent quality correlation; reversed pair order tests
whether arbitrary presentation position changes the preferred underlying summary.
